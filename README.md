# Аукционы Хьюстона — мобильное приложение (PWA)

Ставится на iPhone и Android прямо по ссылке. Работает без интернета, данные обновляются сами.

## Как обновить данные
1. В проекте собирается новый дэшборд `hubN.html` (в нём `const DATA={...}`).
2. `sh tools/build.sh /mnt/project-files/hubN.html` — пишет `data/*.json` и новую версию `sw.js`.
3. Закоммитить и запушить в `main`: GitHub Pages выкладывает за 1–2 минуты, у всех пользователей приложение подтянет новые лоты при следующем открытии.

## Файлы
- `index.html`, `app.css`, `app.js` — само приложение
- `sw.js` — офлайн-кэш и обновления, `manifest.webmanifest` и `icons/` — установка на телефон
- `data/index.json` — список дат и версия, `data/<дата>.json` — лоты одной даты
- `vendor/tess/` — чтение напечатанного VIN (Tesseract.js, Apache 2.0)
- `vendor/zxing.min.js` — сканер штрихкодов VIN (ZXing, Apache 2.0)
- `tools/build_data.py` — превращает DATA дэшборда в файлы приложения

Заметки и избранное хранятся на телефоне каждого пользователя (localStorage).
